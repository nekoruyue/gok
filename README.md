## 二、本地怎么看

在仓库根目录跑：

```
py -m http.server 8801 --bind 127.0.0.1 --directory "05_宣传发行/官网"
```

然后打开 `http://127.0.0.1:8801/`。

不用服务器直接双击 `index.html` 也能开，但 `file://` 协议下背景图有时会加载不出来，建议还是起服务。

## 三、怎么部署出去

### 前提：三个页面都是纯静态

没有后端、没有构建步骤、不需要 node。整个目录 14MB 出头，扔到任何静态托管都能跑。

### 路线 A：GitHub Pages（推荐，免费，带宽软限 100GB/月）

1. 在 GitHub 上建一个**公开**仓（比如 `gokworld-site`）
2. 把 `05_宣传发行/官网/` 里的东西当成仓库根目录推上去
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch` → 分支选 `main`，目录选 `/ (root)` → Save
4. 等 1–2 分钟，访问 `https://<用户名>.github.io/gokworld-site/`

**注意**：`has_pages` 开关没打开的话，推上去的东西是没有网址的。之前 `gok-vein-gambit-preview` 那个仓就是这样，201MB 推上去了但 Sites 是 404 —— 推代码和开 Pages 是两件事。

### 路线 B：Cloudflare Pages

免费、没流量限制、国内一般比 GitHub Pages 好开。连 GitHub 仓，构建命令留空，输出目录填 `/`。

## 四、发布前要守的口径

这些是 `00_资源总览.md` 第五节的红线，门面页已经按这个写了：

- 六方 + 一个已沉的历史阵营（雪都）。卡牌里的「八阵营」是把雪都也算进去了，不是改了口径
- 学院 ≠ 普卫岛：普卫岛善良中立（劝架），学院混沌中立（暗杀）
- 深雪 = 雪都初代领袖，**不是末裔**
- 西昭古堡 = 历史形态，当代西昭 = 部落联盟
- 不写「没有代价的胜利」

### 两条硬规矩（2026-11-15 主人定的）

**对外一律用精二立绘。** 所有图片——官网、群文件、宣传物料——图源只认 `03_美术/立绘/精二/`（38 个文件 / 36 位角色，单张十几兆，用前压 webp）。**人物介绍卡不要再用了**，有些卡上的设定信息是错的。本站的七代号和角色立绘都是从精二目录重新生成的，压缩脚本见 `$TEMP/goksite/mk_portrait.py` 那一套写法：宽缩到 620、webp q82，十三张一共 1.21MB。

**B 站账号是「希斯蒂娜Shextina」。** 不是「小猫月月的肥鱼」，后者是个人号，跟 IP 没关系，别往官网上挂。

### 还有两条要注意的地方

**一、立绘数量别写 41。** `05_宣传发行/群文件包/.../00_一页看懂_v1.md` 里写「41 张角色精二立绘」「41 位人物档案」，但实测是 38 个文件 / 36 位角色。这是口径残留清单里的 P0，门面页刻意没写具体数字。

**二、阵营到底是「六方」还是「七方」，现在两边对不上。** 一页看懂列了七个还在的势力（帝国 / 共和国 / 灰港 / 普卫岛 / 学院 / 西昭 / 洛斯汰），总览写的是「六方 + 雪都」。门面页的写法是「七个还在的势力，加一个已经沉下去的」，**没有用「六方」这个词**，就是为了不跟总览打架。这个口径等主人定了再统一。
