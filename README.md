# 戈克世界

> 2034 年伽马射线暴之后，世界归零；千年后人类捡到「戈克」与「魔法」，然后为了谁说了算打了很久的仗。

这是《戈克世界》的对外站点，纯静态页面，没有构建步骤。

## 页面

| 文件 | 是什么 |
|---|---|
| `index.html` | 门面：一句话、三个词、阵营、三扇门 |
| `lore.html` | 世界观介绍 |
| `atlas.html` | 专题地图（地形 / 势力 / 航路 / 城市 / 历史 / 生物群系，六层可切换） |
| `ancient.html` | 古地图（千年前的口径） |
| `assets/` | 90 个图像素材 |

## 本地看

```
py -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。直接双击 `index.html` 也能开，但部分背景图在 `file://` 下可能加载不出来。
